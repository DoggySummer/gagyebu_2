C. 전체화면 입력 페이지

별도 페이지로 이동해 한 항목을 차분히 입력. 필드가 넓어 결제수단까지 편하게 넣을 수 있지만, 매번 페이지를 열고 닫아야 해서 여러 건 연속 입력엔 번거로움.

참고: 어느 방식이든 항목을 좌로 스와이프하면 삭제, 탭하면 수정으로 동작하게 할 예정입니다.
